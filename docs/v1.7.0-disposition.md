## C. 发布说明中端口不适用/既有覆盖的条目（摘要）

- **纯 npm / Node 运行时**：`pi update` 的 WSL 检测、npm 托管安装校验、undici 安全更新、NodeExecutionEnv
  的 `git var GIT_SHELL_PATH`（端口用 `Process.Start` + `GIT_TERMINAL_PROMPT`）、`wl-copy` MIME 探测、
  AuthStorage 时间戳测试 flake 等——端口不是 Node 程序或无该依赖。
- **TS 类型系统契约**：`render()` 返回 `readonly string[]`、tagged union 迁移（`RolloutHost`/`PluginSource`/
  `SeriesResult`/`Wrap`/`SignalState`/`CommitResult` 等）、`VariantRef`→`LiveRef`——端口用 C# 类型与
  `JsonConverter` 表达，不需要也不应照搬 TS 的形状字符串。
- **上游既有能力**：Google `supportsStrictMode` / xhigh 映射、retry 分类器补强、`rawStopReason`、
  `promptCache` / `supportsMidConvoEffort` / `supportsMidConvoToolChanges`、Copilot decision 模型按账号过滤
  等已在 v1.5.2 / v1.6.0 对齐时落地（端口 `git log -S` 可复核）。
- **端口无此子系统**：chord sync / web 构建 / p2 / p3 的改动全部不计入本轮。
