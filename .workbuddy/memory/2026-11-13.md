## 文档：上游 pi 插件接入（docs/plugin-integration.md）

- 新增 `docs/plugin-integration.md`，一页讲清「C# 侧怎么用原版 pi 插件」：
  - 两条通道：源码插件（`.ts/.tsx/.js/.mjs/.cjs/.jsx`，Jint + Babel 进程内转 CommonJS，一个扩展一个 engine）
    vs 程序集插件（`.dll`，`AssemblyLoadContext`，入口为唯一的 public `IExtensionEntry`）。
  - 分派点 `CompositeExtensionModuleLoader`（`Core/Extensions/Js/JsExtensionModuleLoader.cs`），
    发现逻辑在 `ExtensionLoader.DiscoverAndLoadExtensions`，目录顺序：项目 `.pi/extensions` →
    `<agentDir>/extensions`（`~/.pi/agent/extensions`）→ `-e` / settings packages。
  - 目录入口解析：`package.json` 的 `pi.extensions` → `index.ts` → `index.js` → `index.dll`。
  - 能力边界表（已桥接 / 降级为 warning 的 renderer 注册 / 直接抛错的 provider、`ctx.ui.custom`、
    `process.exit`、`fs.watch`）；Promise 由宿主泵、无事件循环；插件非安全边界。
- 同步修掉 `docs/usage/03-pi-codingagent.md` 里「扩展必须编译成 .NET 程序集」的过期说法，
  并在 `docs/usage/README.md` 的专题参考列表加上新页链接。

### 结论要点（后续复用）

- 上游 TS 插件确实可以原样加载，`Assets/examples/extensions-typescript/hello.ts` 是可直接跑的验证样本；
  `samples/Pi.Sample.Extension` 是 C# 侧对照（csproj 必须 `Private="false"`，否则契约程序集重复）。

## 文档：应用里集成（docs/embedding-plugins.md）

- 新增 `docs/embedding-plugins.md`，回答「应用程序怎么用 pi.net + 上游插件」，两种形态：
  - 进程内 SDK：`DefaultResourceLoader(additionalExtensionPaths)` + `Sdk.CreateAgentSessionAsync`
    + `BindExtensionsAsync`。
  - 子进程 RPC：`pi --mode rpc` + `RpcClient`（`FileName` 必须显式设，默认是 `Environment.ProcessPath`）。
- 记录的真实坑（都对过源码）：
  - 自己 new 的 `DefaultResourceLoader` 必须自己 `ReloadAsync`（`Sdk.cs:533` 只在自己创建时 reload），
    否则扩展集合为空且不报错。
  - `BindExtensionsAsync` 是 `session_start` 唯一触发点（`AgentSessionBuild.cs:1140`）；不调则工具在、
    插件初始化与 `resources_discover` 全不跑。
  - 不传 `UiContext` → `NoOpUIContext`：confirm 恒 false、input null、notify 丢弃。
  - `ExtensionMode` 只有 tui/rpc/json/print 四值，没有 app；插件用 `ctx.hasUI` 判断 UI。
  - `additionalExtensionPaths` 传目录按「包」解析（`pi.extensions` 或 `extensions/` 子目录），
    根目录散装 `.ts` 会报 `Cannot find extension module`。
  - `RpcClient` 没有公开回复 `extension_ui_request` 的方法（`SendAsync` internal）——这是端口的缺口，
    文档里如实标了；协议本身完整（回 `{"type":"extension_ui_response",...}`）。
- 交叉链接：`plugin-integration.md` 顶部指向新页，`docs/usage/README.md` 专题参考补两条。
