### 卡住的坑：GitHub 拉不动，报 `CONNECT tunnel failed, response 502`

排查结论（都实测过，别再重复试）：

1. 这不是 GitHub 的问题，也不是仓库的问题。**根因是 Clash Verge 没启动**：
   `clash-verge-service` 服务在跑，但 GUI 没开 → `127.0.0.1:7897` 无监听，
   注册表 `ProxyEnable=0`，只有个残留的 `ProxyServer=127.0.0.1:7897`。
2. 工具环境里的 `http_proxy/https_proxy` 指向 **127.0.0.1:63527**，它是 WorkBuddy 自己的
   `sandbox-cli.exe` 透明代理，不是用户代理；上游不通时它返回 **502**，
   看起来像「代理报错」其实是沙箱代理没上游。
3. 绕过代理直连（`env -u http_proxy ... git ls-remote`）也不行：`github.com:443`
   21 秒超时。`dangerouslyDisableSandbox` 同样超时——**本机访问 GitHub 必须走 Clash**。

**可复用的解法**：启动 `D:\kf\ClashVerge\Clash Verge\clash-verge.exe`，等 7897 起来后
git 显式指定代理，不要依赖环境变量：

```bash
git -c http.proxy=http://127.0.0.1:7897 -c https.proxy=http://127.0.0.1:7897 fetch --all
```

## 第五十二批：本地验证实跑（durable soak：崩溃恢复 / fan-out / 内存）

写了 `tools/soak/`（gitignore，仅本地）：三个阶段全部 PASS，总耗时 6s。
- **崩溃恢复**：25 任务 × 真杀进程 4 轮（exit 137）→ JSONL 重放恢复、全部 Completed、
  副作用审计干净（只重跑未落提交的阶段）。
- **fan-out**：1 父等 50 子，415ms。
- **内存**：1500 会话 + SQLite + retention=100ms → 缓存恒 0，堆增 0.1MB。

**踩坑（都是工具自己的）**：
1. 父进程恢复调度器也会跑阶段处理器——副作用路径（FxPath）必须在父进程也赋值。
2. Waiting 任务唤醒后重进同一 phase，处理器必须自己判断「子任务都落定→推进下阶段」，
   否则活锁（checkpoint 停在原相位）。
3. 阶段处理器是 `Func<...,Task>`，async lambda 不能返回值；要多状态就多次 CommitAsync。
4. **使用边界**：崩溃后密集开关存储会与回收删除竞态（OpenAsync 抛 ENOENT），
   上游 TS 同样如此；生产低频重开无碍，工具用重试吸收。
5. 注册表忘了 Install 扩展 → 任务永远 Pending（诊断输出 `status=Pending checkpoint=s1` 即此症）。

结论更新：durable 的 soak 坎已过；剩余：CI 补 linux matrix、非交互测试子集进 CI。
