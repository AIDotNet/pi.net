## 本轮落地：两项修复

1. **`c8ec752cf` 补齐**（`src/Pi.CodingAgent/Utils/ToolsManager.cs`）：新增 `GetReleaseTarget`
   只映射 x64/arm64 × darwin/linux/win32；`EnsureToolAsync` 在离线/Termux 判断后、**任何 HTTP 之前**
   给「用系统包管理器安装」warning 并返回 null；`DownloadToolAsync` target 判断放在版本查询之前。
   `ToolConfig.GetAssetName` 签名由 (version, plat, arch) 改为 (version, target)。
   回归 `ToolsCorpusTests`：arm/ia32 零请求 + 精确文案、9 条映射向量；语料 `toolsEnsureTool` 的
   `aix/x64` 过期期望手工同步（生成器 `gen-coding-agent-tools-corpus.mjs` **从未入库**，语料是快照）。
2. **Windows shell 清理失败定性**：不是 Git Bash 进程树边界、不是实现缺陷，是**用例竞态**。
   诊断证据：本机直接 `taskkill /F /T` 能 1 秒杀掉 `bash -c 'sleep 8'`（bash 对单命令 exec 优化，
   PID 即 `/usr/bin/sleep`）；项目路径按 marker 等待后 `_activeChildPids=[71228]`、清理 1.1s 结束、
   exit=1；而原用例固定 300ms，本机 marker 要 865ms 才出现 → 清理时集合为空。
   修法：`EnvTests.Shell_CleanupTerminatesActiveProcesses` 改回 marker 同步（对齐上游
   `env-node.test.ts:738`）+ 5s `WaitAsync`，**实现不动**（cleanup 只杀已登记进程，与上游一致，
   别加 `_cleanedUp`）。残留边界：清理早于 PID 登记时该进程不受管，与上游相同，需单独立项。

文档：CHANGELOG 加 `[Unreleased]`；`upstream-1.5.0-delta.md` §5 两条待核收口 + 新增 §8（含诊断表）；
