## 上游 v1.4.0 之后 88 个提交的移植评估

结论：**不整体搬迁**，按“跟随稳定 tag、不跟 main”的既有节奏走。

- **P0 必修（13 项）**：MCP OAuth 只放行 http/https（端口 `OAuthTypes.SafeUrl` 只挡
  javascript/data/vbscript，ftp/file 仍过）、不可信输入加固、Anthropic 系统消息跨丢弃的
  assistant 保留、Anthropic per-message effort 顶层、faux cache write 不计入 input tokens、
  Kimi K3.1 家族、GPT-6.1 Terra/默认 gpt-6.1-sol、OpenCode 协议专用端点（端口 baseUrl 来自
  1.4.0 目录快照，需重新生成）、pi.exec spawn 错误保留、包安装失败仍可启动、grep 孤立 CR、
  provider id 含斜杠、嵌套引用块指数膨胀。
- **P1 可选（~17 项）**：/ir 支持 URL 导入（端口 `/import` 只吃本地路径）、durable Harness
  只读、HTML 导出深会话/系统消息、pi-messages responseModel、模型选择器显示模型名、
  TUI 一组渲染与键盘修复、fork 单 fd、durable 工具交接后续跑、thinking level 记录等。
- **单独立项（P2）**：chord/durable 的 watch 体系（Watch/Watchable/NativeWatchable/PendingOps/
  采纳时发布）与 appendText、延迟提交、Delta 拷贝优化——接口重构，不混进修 bug 版本。
- **不适用（~35 项）**：npm/Bun/CI/发布流水线、Node/workerd SQLite 专属、纯文档与贡献者名单。
- **已被端口覆盖**：OpenRouter 上报成本（1.4.3 已落）、流式工具参数增量解析（6 个 API 已用
  `ParseStreamingJson`）、exec 跨块 UTF-8 解码（`Encoding.UTF8.GetDecoder` + pendingAnsi）、
  Gemini const→enum（端口只走 `parametersJsonSchema`，const 合法）。

下一步建议：先发 1.4.4 收 P0 那批；等上游出下一个稳定 tag 再评估是否对齐 1.5.0。
