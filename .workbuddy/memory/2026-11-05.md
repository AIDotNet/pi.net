### 两个操作坑

- **`dotnet pack --no-build` 是增量的**：`artifacts/` 里已有同名包时它静默跳过（无任何输出），
  nuspec 里的 `repository commit` 会停在上一次的 HEAD。想刷新必须先删旧包。CI 是干净 checkout，不受影响。
- **本机 `api.nuget.org` 被 DNS 劫持到 `nuget.azure.cn`**（301 重定向）。查版本要用镜像域名；
  本地 `dotnet nuget push` 也会受影响，所以发布只走 GitHub Actions，不在本地推。
- git remote 是 HTTPS，本机非交互 push 会失败（无凭据）；SSH 可用（`Hi xuzeyu91!`）。
  推 tag 前要把 fetch 和 push 两条 url 都换成 `git@github.com:AIDotNet/pi.net.git`（只改一条不生效）。
